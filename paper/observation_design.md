# Observation 章节设计（E80，2026-09-30 用户指令）

用户要求：observation 不是单纯列数据说方法好，要**延伸出规律**——
为什么好、是不是各模型通用。三个创新点各配一组观察。本文档 =
调研结论 + 机理叙事 + 数据映射 + 论文安放建议，供 tex 重写时使用。

## 0. 调研：其他论文的 observation 怎么写

| 论文 | observation 形态 | 对 TLI 的启示 |
|---|---|---|
| SnapKV | position bias 现象（attention 聚集于 sink + prompt 末「observation window」）→ 现象直接变成方法（末窗口 pooled attention 当选择信号） | 现象→方法的「短路径」：一个可视化/统计观察直接蕴含设计 |
| Quest | decode 稀疏性 + PPL 证据 → 页粒度 top-k | 用「替代指标」（PPL/mass）证明稀疏无损，再谈选择 |
| MoBA | **无 observation 段**——「less structure」设计原则驱动 | 对照组：设计原则驱动论文可以不写观察，但 TLI 是 training-free，**先验从哪来必须由观察论证** |
| DSA (DeepSeek-V3.2) | 无 observation 段——训练对齐驱动（KL 对齐 attention 分布，warm-up 1000 步） | 关键对照：DSA 用**训练**换选择能力；TLI 用**位置先验**换。这条分界线本身要写进论文 |

**顶会 observation 四要素范式**（SnapKV/Quest 共同点）：
①现象（真实模型+真实数据的统计/可视化，非合成）②机理抽象（为什么
如此——给出结构解释而非只报数）③设计蕴含（观察直接导出方法的
设计约束）④边界（何时不成立——negative result 增可信度）。

**TLI 的独特资产**：系统性 negative results（口径鸿沟 E72、训练投影
e2e 崩 E71-B、自适应无杠杆 E75/E79a、非线性降维不可行 E76）——
多数论文没有第④要素，我们有四条。观察的「边界刻画」是 TLI 论文
相对 SnapKV/Quest 的方法论增量。

## 1. Observation A：注意力 mass 的位置分段异质性（分区 + 异构 method 的根基）

### 现象（数据）
- softmax mass 三层结构（E1，10 条真实 trace + needle/natural）：
  **sink 0.37–0.71 / near 0.16–0.29 / far 0.02–0.29**——不是「双峰」
  而是位置分段的密度台阶；far 段内 mass 极稀疏且 GQA head 间
  极不均（L03 head3 独占 0.804，同层其他 head ≈0）。
- far 关键 token 的稀疏度决定一切：far mass 0.02–0.29 集中在
  少数 token（musique 多跳证据句），near mass 平铺在整段窗口。

### 机理抽象（为什么异构 method 有理）
两段的**统计性质相反**，最优索引粒度因此相反：
- **near 段密集平稳**：候选 token 分数普遍高且彼此接近 → 粗索引
  （avg 块均值）不会漏；E73 near 压维 d4≈d64 平坦 = 该段信息
  冗余大、区分度低（反正都高 mass）。avg 块分还比 minmax 省
  一半索引存储。
- **far 段稀疏尖锐**：少数关键 token 承载几乎全部 far mass →
  漏一个代价大 → 需要 **minmax 上界**（区间算术打分 no false
  miss，E4c）+ token 级精筛（≈oracle，L03 0.999）。
- 谱系视角：sink/swa 是「免打分区」的极限（mass 大 + 位置确定
  无需打分）；分区异构 method 是这个谱系的中间态——**分区不是
  拍脑袋切三段，而是位置-密度台阶的自然映射**。

### 规律延伸（不止「我们的方法好」）
1. **诚实边界（重要）**：method 组合本身增益小（E64i：near 侧
   method 自由度 ≤0.003）——分区的真实增益是**预算防挤出**
   （E4c anti-eviction：far 独立预算后 far capture 反超 TIA），
   异 method 是「便宜且等效」的工程选择而非精度来源。论文
   必须这么写，否则 reviewer 复现 E64i 会打脸。
2. 预算口径的反转规律（E72）：trace 宽预算下 mono 16/16 胜、
   e2e 紧预算下分区胜 → **分区收益本质 = 紧预算下的预算分配**，
   这条观察同时是方法论贡献（离线代理口径必须贴部署预算）。
3. 通用性：位置分段结构在 8B/32B 双模型、13 真实任务 + 合成
   needle 全部复现（32B far 双峰复现、跳 41/64 层 precision
   0.993）；密度台阶的具体比例任务相关（far 让渡边界，E74）。

### 论文写法建议
放 §2 Motivation 第一节（对应 tex 现有偏斜段升级）：一张
「位置-mass 密度台阶图」（三段台阶 + far 段内 head 极不均
插入图）→ 直接导出两级索引的区域结构。**配图 = 终版 Fig2
左侧 panel 或独立小图**。

## 2. Observation B：预算分配的饱和性与平坦性（α/β 让渡的根基）

### 现象（数据）
- far 侧预算饱和：128–256 token 后 mass 捕获饱和（E8b）——
  far 侧多给预算买不到 mass；
- 让渡有正收益：β.375 vs β.25 在全部真实任务族成立（E74：
  多跳 +0.77、musique +1.94 最 far-heavy 增益最大——far 稀疏
  已饱和 + 分区防挤出 → 让渡 near 的边际收益高）；
- 参数面平坦：β 0.25–0.75 平坦（E64g 热力图）、α 单调至边界
  0.125；per-task oracle +0.08（E75）、per-layer oracle
  +0.0008（E79a）——双重否定自适应的杠杆。

### 机理抽象（回答用户：「之前的方法浪费预算了吗？」）
**是——单池 top-k 方法结构性浪费 far 预算**：Quest/TIA 单池
竞争下，near 段海量中高分 token 天然挤占配额，far 段 0.02–0.29
的少数关键 token 因绝对分数低被挤出（E4c 防挤出动机的定量
版本）；而 far 侧预算一旦独立，128–256 即饱和。**两头夹出
让渡空间**：far 不需要那么多（饱和）+ near 挤得掉别人（挤出
效应）→ 预算应向 near 让渡（β>份额）。
- 平坦性的正面转译：分区预算**不需要精调**（oracle 双重否定
  = 对配置误差鲁棒）→ 部署简单性论据。这是 counterintuitive
  转折点：「我们不提出一个需要精调的参数，我们证明这个参数
  不需要精调」。
- 让渡的边界 = far 关键 token 稀疏度（E74）：真实任务全族成立；
  合成 far-dense（multikey_3 far 候选爆炸）失效——far 侧预算
  粒度主导。给出「何时分区」的适用域。

### 规律延伸
1. 自适应无杠杆的普适结论：α/β 在任务与层两个粒度都平坦
   （E75 +0.08 / E79a +0.0008）→ per-request 动态信号的最佳
   用途是**跳层 gate**（安全价值）而非配比分派（无精度价值）；
2. 长度梯度：分区收益区 = 超长上下文（RULER L16384 +0.91，
  长度梯度 −0.14→−0.25→+0.91 干净成立）→ 短上下文分区中性、
  长上下文分区放大——**分区是长上下文方法的设计约束**；
3. 通用性：β 依赖是任务级形态差（LongBench 多跳 β.375 优 /
  RULER needle β.25 优）而非请求级信号——静态双臂按形态
  二选一 = 收益/复杂度最优（E74+E75 合并结论）。

### 论文写法建议
放 §4.1/§4.4 消融的观察导语 + §2 的动机第二段。「浪费预算」
对比图（单池 vs 分区的 far capture 曲线随 far 预算变化——
已有 E8b 敏感性数据可重画）是候选 Fig（α×β 热力图 = 平坦性
证据，已规划为终版 Fig4）。

## 3. Observation C：降维自由度来自位置先验（子空间/降维的根基）

### 现象（数据）
- 尾维 32/128（25%）子空间质量不打折（E3：0.729 vs 全维
  0.732），random 32 崩溃（0.32）、高频 32 崩溃（0.137）——
  「哪个 25%」比「压到 25%」重要；
- 两段互补（E73）：rope 低频尾 16 单独 0.576 + nope 尾 16
  单独 0.383 → 拼接 0.796（+0.22 组合增益）——位置感知段
  与内容稳定段各取所长；
- far 区无监督 PCA d16 近无损（E65：0.766 vs 0.804）；跨
  kv-head 共享 SVD 基 d16 8/8 追平 tail32 且优于 per-head
  （E76）——head 维度也有冗余结构。

### 机理抽象与规律延伸（本节是「延伸规律」最强的）
**三层证据链收束到一个普适规律：training-free 的降维自由度
来自位置先验（分布无关结构），而非学习或自适应**：
1. 任意子空间崩、位置结构子空间稳 → 自由度不是「任意 32 维」
   而是「位置稳态那 32 维」；
2. 无监督 PCA（far 区内容谱集中）也成立 → 但 per-head 不如
   跨 head 共享（GQA head 冗余）→ **MLA 式单投影缓存在纯
   GQA 模型上 training-free 可行**（E76 新发现，DeepSeek 类
   模型的 latent 索引是它的训练版）；
3. **口径鸿沟定案自适应不可能**：监督投影 trace 成立 92–94%
   （E66）→ e2e 崩（E71-B，投影基对 decode q 分布漂移脆弱
   vs 位置先验与 q 分布无关恒稳）；q 自适应三路否定（E5 相关
   ≈0 / E72 cavg 垫底 / E75 oracle≈0）；非线性流形学习双判
   否定（E76：UMAP 保邻域不保选择排序 −4pt + 成本四个数量
   级；t-SNE 三重不可行）。
- **与 DSA 的分界线**：DSA 用训练（KL 对齐 attention 分布）
  换选择能力，可以学任意投影；training-free 只能用分布无关
  的位置先验——**口径鸿沟（trace 离线成立 ↔ e2e 崩）是这两
  个流派的数学分界**，不是我们的实现失误（这是把 negative
  result 升格为流派级观察的关键句）。
- 通用性：32B 复验「机制存在、强度递减」（lowfreq 0.66–0.87
  ≈ full128 差距 ≤0.08；random 退化 0.149→0.5+ 弱化）——
  诚实报告；near 区可激进压缩（d4≈d64 + 滑窗兜底）与
  Observation A 的区域异质性互为印证。

### 论文写法建议
放 §2.1（现有 tail32 机理段升级为 observation 叙事）+ 贡献 #1。
配图 = 终版 Fig2 右侧 panel（tail32 两段互补 + 降维方法族对比，
E65/E73/E76 数据齐，可出图）。
