## 设计

两臂配对（同 n=200 同 seed=42 天然配对）：

| 臂 | 配置 | GPU |
|---|---|---|
| perlayer | 8 层覆写逐层最优（L4/24/28=单池(0,0,0)、L8=(.375,.625,.125)、L12=(.875,.625,.125)、L16=(.625,.625,.125)、L20=(.25,.375,.125)、L35=(.0625,.125,.5)），其余层保冠军 (.25,.125,.625) | GPU0 |
| uniform | 全层冠军 (.25,.125,.625) | GPU1 |

13 任务 LongBench 串行。harness = pred_e117_perlayer.py wrapper
（runpy 三层包装 + per-layer receipt 落盘 + 32/32 红绿测试）。

perlayer 13 任务平均分显著优于 uniform（配对 bootstrap CI 不含 0）→ GO 并入生产；
否则 NO-GO 关闭（不预设方向）。
