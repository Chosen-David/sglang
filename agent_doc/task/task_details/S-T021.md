## 语义判定（主 AI）

- **动态 = 运行时逐序列逐层**：当前 seq 在当前层根据当时合法可见信息生成
  α/β/γ，**不是**层号查表或任务名查表（GPT §0 明确，用户「动态」采纳
  同一语义）。E117 静态 8 层表 NO-GO **不否定**本目标（机制不同：内容
  自适应 vs 层号查表），但作为既有阴性记录在案。
- **静态 mavg (.25,.125,.625) 保留为对照/安全回退**，不是被替代关系；
  统一 mavg 固定参数与 FullKV 在所有筛选/确认中同协议锚点。
- **E116b（#167/S-T019）不停**：GPT 明确「不取消或控制已在运行的作业」；
  其产出 = 静态新口径锚点 + fullkv 基线复用数据 + 论文「动态 vs 静态」
  消融行素材。
- γ off / cavg 线维持 E123 判决关闭状态，不进主线。
