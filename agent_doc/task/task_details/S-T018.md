## 语义（主 AI 判定）

γ off = 取消 near/far L2 配额分割（原 nt_near=nb_near·bs·γ 保留配额 +
far 拿剩余），全部 mid 候选在统一 K2_mid 预算内单池 topk 竞争；sink/swa
保护带与 L1 β 预算语义不变。量纲注意：far minmax 分与 near avg 分混池
量纲不一致，配 cavg（cluster avg 与 near avg 量纲一致）最合理——用户选
cavg 正是如此。
