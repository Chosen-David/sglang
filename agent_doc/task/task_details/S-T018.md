# S-T018：E122 γ off 自由竞争 + E123 cavg 对比小试

## 来源

- 用户 2026-10-10 晚指令：试 cavg 的 (α,β,γ)=(0.25,0.5,0.125) 与
  (0.126,0.126,γ off)——「off 指的是自由竞争」——能否优于海选胜出的
  相关方法。

## 语义（主 AI 判定）

γ off = 取消 near/far L2 配额分割（原 nt_near=nb_near·bs·γ 保留配额 +
far 拿剩余），全部 mid 候选在统一 K2_mid 预算内单池 topk 竞争；sink/swa
保护带与 L1 β 预算语义不变。

【量纲更正（GPT 7c3190921 核验 2026-10-10）】原「配 cavg 簇分与 near
avg 量纲一致」**无实现依据**已撤销：`_far_token_score` 为 GQA group-sum
纯点积（无界），near `p` 为 softmax 概率（[0,1]），混池 far 侧系统性霸榜
风险高；`far_method=avg` 只改 L1 分数源不归一化 L2 簇分。E123 cavg_off 臂
按「未归一化混池实测」报告并挂 caveat；matched 归一化对照（far 段
row-wise softmax/minmax，quota/free 两臂同修同源）列为 E123 判决后条件项。
