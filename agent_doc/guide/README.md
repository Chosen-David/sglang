# guide：人类目标、编排意见与硬约束

本目录存放人类发布的 sglang 项目目标、优先级、架构约定、禁止事项和验收
要求，规范入口是 `GUIDE.md`（人类自行创建）。

**本项目的最高优先级指南是根目录两个映射文件（AI 只读、绝不修改）：**

- `/home/wangyuanshuo02/sglang/TASK.md`——用户私人任务设定
- `/home/wangyuanshuo02/sglang/论文indexer.md`——论文口径权威定义

AI 对指南的处理责任：

1. 开始、恢复或接到指南更新时，阅读上述文件与本目录 GUIDE.md（若存在），
   确认来源、版本和适用范围。
2. 将每项适用要求落实到 `agent_doc/task/TASK.md` 的稳定任务 ID，以及
   详情中的方法、依赖、优先级和验收标准。
3. 对要求逐项回应：怎样落实、当前结果与证据、尚未完成的部分；受阻时
   说清原因、缺少的条件和下一步。
4. 发现要求矛盾或执行条件不足时，在 `agent_doc/advice/` 提出证据与
   待决定项；未获新决定前保留原要求及阻塞状态。

本目录不放 AI 生成模板或 `.gitkeep`；Git 不保存空目录，人类初始化时
直接创建 `GUIDE.md` 即可。
