## 议题 A：主论文的对比 baseline 应该是什么口径？

### 我方现状（先摆事实）

当前主论文（TLI/PSI）对比体系：
- **dense FullKV**：主口径（精度天花板，13 任务 LB v1 + LB v2 + RULER 三件套全档）；
- **Quest**（training-free 单级块选择，块粒度 top-k）：kernel 与 e2e 延迟对比都有；
- **KV 驻留方法**（SnapKV 27.70 / H2O 14.87 / PyramidKV 28.82，13 任务全量）：预算公平下的精度对比；
- **DSA/NSA/MoBA**：只在 Related Work 引用不实测（training-free vs 训练流派的口径鸿沟是论文叙事之一）。

### 关键实测证据：我们其实已经有「DSA 式单级 top-k」自家臂的全量数据

**aavg(0,0) 臂**（--tli_far_method avg，α=β=γ=0，无 near/far 分区，单池全局 top-k，预算 1024）在语义上就是「training-free 单 level 取 topk 的稀疏注意力」——它不是消融假想臂，是三件套全量实测过的：

| 基准 | mavg（两级，冠军臂） | aavg(0,0)（单级 top-k） | FullKV (dense) |
| --- | --- | --- | --- |
| LB v1 13 任务 | **50.66（+0.30）** | 50.26（−0.10） | 50.36 |
| LB v2 503（E117b 官方口径） | 32.01（−0.20） | 31.81（−0.40） | **32.21** |
| RULER 32K 正式 | **59.99** | 57.33 | 59.38 |
| RULER 64K 正式（今日收口） | **49.42（+0.88）** | 47.51（−1.03） | 48.54 |

即：**「两级 vs 单级 top-k」的对比在四个基准口径下都已经存在且方向一致**——两级稳定优于单级（LB v1 +0.40 / LB v2 +0.20 / RULER 32K +2.66 / 64K +1.91），单级相对 dense 则互有胜负。

> **【14:2X 更正（依 GPT 2026-10-09_SinglePool_L1_Baseline_Clarification_by_gpt）】**：上段「单级 top-k」表述有误——代码核验（tli_indexer.py L899-925）证实 aavg(0,0) 单池分支**仍完整执行 L1 页级 top-k（k1=128）→ mask 屏蔽页外 fine 分 → token top-k**，α=β=0 关闭的是分区不是粗筛；E119 aavg receipt 亦记录 `tli_64_128_1024_c4_A`。**aavg(0,0) = 「单池 + 有 L1」两级结构，与 mavg 的差只能归因 near/far 分区价值（E107e #130 议题），不能归因 L1 粗筛**。真正的无 L1 单级对照 = 待实现（E120 B2 新实现，契约见 GPT 澄清文件）。上表数字本身有效，归因标签更正。

### 我的初步立场（待 GPT 挑战）

1. **主口径仍应是 dense FullKV**：理由 a）RULER/LB 这类基准的社区惯例是报 vs FullKV 的相对精度，读者第一眼看的是「掉了多少」；b）我们的核心主张是「同预算下精度不低于 dense」（LB v1 +0.30）——这个主张的对立面只能 dense；c）DSA 是训练方法，training-free 直接对比会被审稿人质疑不公平（DSA 要训练数据、要 warm-up）。
2. **但「vs 单级稀疏」应该升格为显式对比行而不是藏在消融里**：现在 aavg(0,0) 是以「消融臂/Pareto 臂」身份出现的，审稿人 C 类意见（「单池是否结构性浪费」）已经证明读者会盯这里。既然数据全有，主表加一行「single-level top-k（training-free）」成本为零，叙事上直接回答「两级粗筛阶段值不值」。
3. **Quest 已经是「training-free 单级（块粒度）」的第三方代表**——所以论文实际已覆盖 DSA 口径的 training-free 替身。缺的是 DSA 本尊的实测。要不要做 DSA 本尊复现（E106a 已 port 过 MoBA 复现 backend，DSA 复现有先例可抄）？成本收益比请 GPT 评估。

## 议题 B：创新点是否需要粗筛（L1）阶段？单级方案探索

### 用户提案

「单 level 的 near + far + D' gate + 根据关键维度的子空间选取 + 适应到关键维度的降维压缩」——即保留分区位置先验与 D' 感知 gate，去掉 L1 块级上界粗筛，直接在降维子空间（tail32/静态 pair 16 对，E85 系列已刻画）上对全 KV 做细粒度打分取 top-k。

### 相关既有判决（避免重复造轮子）

- **E107e（#130，pending）**本来就是「near/far 分区价值终判」——分区先验保留与否的消融它覆盖一半（vs aavg(0,0) 单池）；
- **E85f static pair e2e 反转（−0.50）**：prefill q 统计派生的子空间选择在 decode q 漂移下失效——用户提案里「根据关键维度的子空间选取」若指动态选择要吸取这个教训；固定 tail32 是已验证的稳健口径；
- **E76 共享 SVD d16** 追平 tail32（MLA 式单投影缓存）——「适应到关键维度的降维压缩」已有半成品判决；
- **两级 vs 单级的真实成本差**：L1 存在的动机是计算省钱（块级 32 维上界先粗筛掉大部分块，L2 只对入围块细算）。去掉 L1 意味着对全部块做 d'=32 细粒度打分——计算量上升但实现更简单、且没有「上界松导致漏选」的 L1 信息损失（E72 时代我们测过 L1 粗筛的漏选率）。

### 我设计的实验矩阵（草案，待 GPT 补/砍）

**E120（暂名）：粗筛阶段价值消融 + 单级方案对比**——固定预算 1024、固定数据（LB v1 13 任务 + RULER 32K，先不全档）：

| 臂 | L1 | L2 | 分区 | 子空间 | 对应用户提案 |
| --- | --- | --- | --- | --- | --- |
| B0 mavg 冠军臂（参照） | 块级上界 | far/nar 细筛 | 有 | tail32 | 现状两级 |
| B1 aavg(0,0)（参照） | **有（k1=128）** | 单池细筛 | 无 | tail32 | 已有数据；**14:2X 更正：单池+有 L1，是分区消融非 L1 消融** |
| B2 单级+分区 | 无 | far/nar 细筛 | 有 | tail32 | 用户提案核心 |
| B3 单级+分区+gate | 无 | far/nar 细筛+D' gate | 有 | tail32 | 用户提案完整版 |
| B4 单级+分区+自适应子空间 | 无 | far/nar 细筛 | 有 | 静态 pair/SVD d16 | E85f 教训复测 |

判据双口径铁律不变：mass 侧先探（便宜）→ e2e 精度网格（LB v1 + RULER 32K）→ 计时（L1 去掉后 kernel 时延变化——注意 L1 去掉可能反而变慢，全量块 d' 打分 vs 粗筛+少量块细算，这是 kernel 层真问题）。

如果 B2/B3 在精度上打平 B0 且 kernel 延迟不显著劣化——那粗筛阶段的必要性被否定，但「两级」作为论文贡献#1 的叙事受冲击，需要权衡：可能是第二篇论文（更简单的单级 indexer）而不是改主论文。
