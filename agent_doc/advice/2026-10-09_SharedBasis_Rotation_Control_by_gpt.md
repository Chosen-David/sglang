# 共享子空间的正交方向控制实验

优先级：P2，待严格因果与基础实现验收后开展。面向 min/max 页评分的独立诊断建议；不是要求改用两套子空间，也不是已测收益。

## 依据和适用边界

审查基线：Chosen-David/sglang 的 two-level-indexer 分支，提交 9c7b096f723816aaa3cfc645aebfb1a40789d669。依据是仓库共享子空间/投影路径及 min/max 页评分机制，以及标准正交变换恒等式。下述反例是独立有理数算术核验的作者推导，不是新定理、形式证明器认证或模型实验。

最新适用性复核：c1348dae4a21e8b02a396fee69fd560a32c69753 的相关实现与上述 9c7b096 相同。已检查该快照下九份 advice 及相关实验计划，新增 prefill 审查覆盖因果路由和窗口问题，但未覆盖本项固定子空间内的方向控制；这里只报告有界去重结果，不宣称全仓库或学术新颖性。

固定一个层、一个 KV 头，设共享坐标 z=Pᵀx。对同一个 r×r 正交 W（WᵀW=WWᵀ=I），两级同时改用 P W，则 z′=Wᵀz。共同旋转保持所有未量化查询—键点积；若 P 的列正交，P W WᵀPᵀ=PPᵀ，投影重建也不变。然而轴对齐 min/max 页面包围盒会改变，因此页上界、被选页面和最终候选集可能变化。仅在固定候选集合上，原始 L2 排名保持不变；整条选择流程不承诺不变。

这一结论针对 min/max 包围盒，不直接推广到平均键或聚类评分。量化、逐坐标归一化或非线性 scorer 会引入额外变化，必须关闭或单独记录。

## 一个可算反例

q=(1,1)，页面 A={(1,0),(0,1)}，页面 B={(7/10,7/10)}。令 W=[[3/5,-4/5],[4/5,3/5]]，共同使用 Wᵀq 与 Wᵀk。

- 未旋转：A 页界 2，B 页界 7/5。
- 旋转后：A 页界 32/25，B 页界仍 7/5。
- 三个真实点积始终为 1、1、7/5；只选一页时由 A 改选 B。

两种方向的上界均合法。例子说明方向是粗筛的一个因素，不证明任意或随机旋转更好。

## 最小实验

先确认是否已有获准复用的 post-RoPE Q/K 轨迹。当前已审查的存档汇总不足以代替轨迹张量；没有可用轨迹时保留“未执行”，不要为本建议自动启动 GPU 采样。

1. 固定来源提交、模型/层/KV 头、轨迹哈希、校准与确认划分、P、页面及近远边界、有效 token mask、每 KV 头有效且去重的候选/词元上限（排除 padding，不跨 KV 头取并集）、GQA 聚合和 tie rule。
2. L2 使用未量化共享点积。比较 identity、固定种子的少量正交方向；两级共同使用同一方向，不增加 L2 专用空间。
3. 先固定候选集合核对点积数值误差；对分数间隔大于两倍已核定误差界的候选对核对排序。精确并列采用固定 ID 规则，近并列数值翻转单列报告；不要求浮点位级相等。
4. 再允许 min/max L1 重新选页，记录页界松弛、被选页/候选 ID、真实逐查询头候选质量、最终输出局部误差，以及预处理、摘要维护和选择成本。候选质量不能用 GQA 求和代理冒充。
5. 仅若发现稳定差异，再独立开启现有编码，区分 L1 方向效应与量化误差。不得在确认轨迹上搜索最优方向再报告为泛化结果。

## 对照与通过/失败条件

- 恒等验证失败：先排查不一致变换、dtype、GQA 聚合、候选或 tie 条件，停止收益解释。
- 恒等验证通过且 L1 排序变化：仅确认这一机制在该轨迹发生；不构成端到端质量提升。
- 若探索方向在独立确认轨迹没有改善，或维护成本抵消收益，保留负结果并停止扩展。
- 应把“同子空间不同方向”和“改变子空间”分列；后者不隔离本假设。

成本限已有小轨迹的 CPU 离线分析，零新 GPU、零新增付费操作。主要风险是重复调参泄漏、把选中质量当生成质量、忽略真实实现的量化/布局开销。已有投影与粗筛建议保持有效，本项只补充固定子空间内的方向控制。
