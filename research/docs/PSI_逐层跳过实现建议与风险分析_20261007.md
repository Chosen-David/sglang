## 0. TL;DR

1. **「哪些层能跳 far」是两分解的**：结构层（哪些层永远不做 far 检索）由模型结构决定，**可以且已经静态固定**（DEFAULT_MASK 13/36 @8B，41/64 @32B）；任务边缘层（这次请求用不用检索层）才是动态 gate 的合法领土。
2. **动态 gate 的边际价值未证实**：E67 实测 per-request far 信号在 τ=0.05 时 0/168 层触发——结构层已被静态掩码拿走，剩余层的 far mass 又不够低。E111 的主指标必须是「dynamic vs static 的边际跳层率 × e2e 差分」，而不是「dynamic 能不能跑通」。
3. **预先约定判决标准**：若 dynamic@τ0.005 边际跳层率 <5%（相对 static），结论写「结构静态掩码即终态」，论文 line 41/182 的 per-request gate 表述相应收窄——两种结果都有论文价值。
4. 若做动态，建议用**混合语义**（M3）：结构层静态必跳 ∪ 检索能力层动态判定（p95 统计 + 更严 τ），不要纯信号语义。
5. skip_near（M6）已否决：与论文核心 observation（让渡律，line 79）叙事冲突，E87 near_σ8 musique −1.63 有前科，收益抵不上叙事成本。

## 1. 背景与问题定义

PSI 选择链每层每 decode 步成本约 0.82ms@8K（36 层共 29.5ms/step，e67_gate_benefit）。D' 层跳过在 far mass ≈ 0 的层上把 far 块从 L1 剔除并收缩 far 池（`tli_indexer.py` line 482-484, 512-517），直接兑现省算。

E111 现行计划：三模式接入——
- **dynamic**：prefill 期逐层采集 far 信号（E67 信号定义 + E75 corr 0.924，走 `observe_prefill_q` 同款旁路）→ τ 判定 → decode 期跳 far；
- **static**：现有 DEFAULT_MASK 行为，降级为对照臂；
- **none**：现主表口径，回归保护（gate=none 与现状逐位一致单测）。

**待回答的核心问题**：skip 集合有多少是模型结构决定的（可静态固定），有多少是请求依赖的（必须动态）？动态机制的理论假设（prefill 信号预测 decode 需求）在哪些场景不成立？

## 3. 候选方法矩阵（六种，含分析/弊端/改进点）

### M1 静态结构掩码（现状，DEFAULT_MASK）

**做法**：离线校准混合任务样本，avg far profile < 0.02 的层固定跳过；运行时查表。

**依据**：E6 两群结构 + 32B 复现（41/64，precision 0.993）——「哪些层永远不做 far 检索」是 attention head 功能分化，模型结构指纹。

**优势**：生产免费（编译期常量、无信号、无 τ、CUDA graph 友好）；行为确定性，回归测试简单；32B 已验证。

**弊端**：
- 只能拿跨任务交集（13/36），检索类任务的任务边缘（E6 per-prompt 30/36）拿不到，省算上界被压在 ~36% 层中的保守子集；
- 校准口径是旧协议（near_len=2048 固定），与主表 mavg α.125/β.375/γ.625 的区域定义不一致，掩码本身需在主表配置下重校准。

**改进点**：
- 用主表配置区域定义（swa=128，near_dyn=α·mid）重新校准掩码；
- 作为 dynamic 的强制下界：任何动态语义都不允许「跳过比 static 更少」（见 M3）。

---

### M2 动态 per-request prefill 锁存 gate（E111 现行计划）

**做法**：prefill 末段采样 M≈16 个 q，逐 q-head 全量 softmax 得 per-layer far mass 占比（E60 口径），mean 统计 < τ 的层 decode 跳 far；决策 prefill 一次锁存，decode 零开销。

**依据**：E60 corr 0.97-0.99 + E75 corr 0.924；E5b 证明任务边缘无法离线固定，per-request 信号是唯一剩余路径；论文 line 41/182 已 claim。

**弊端**：
- ⚠️ **prefill 锁存假设对多跳任务系统性不成立**：多跳检索需求是在 decode 中「生成」出来的（模型写着写着才去检索第二跳证据），prefill 统计的是「读 prompt 时」的 far 使用，对生成期才出现的检索需求是低估。E60/E67 只在 ~255 decode 步内验证，长生成/agentic/多轮全部 OOD；
- ⚠️ **边际价值存疑**：E67 保守 τ 下 far 信号 0/168 触发，dynamic 对 static 的增量可能 ≈0（加了信号采集、τ、状态机、batch 复杂度，换来约等于零的省算）；
- mass 阈值看不到 e2e 关键 token（0.004 的 far mass 可能恰好是 musique 答案句）；
- τ 与论文「no tuning」卖点（line 79）存在叙事张力；
- 生产形态成本：batch 内 per-request 跳层集合 → kernel/graph 可变形状工程税。

**改进点**：
- 统计量从 mean 改 **p95**（E60 三口径中 p95 与 decode corr 同样高，且对「少数 q 突然检索」更保守）；
- 混合语义（M3）限制动态判定只在检索能力层上发生；
- 加长 decode（2K+ 步）漂移压力测试进 DoD，直接检验锁存假设；
- 判决标准前置（见 §5）：边际 <5% 就收敛回 M1 为终态。

---

### M3 混合语义：结构层静态 ∪ 检索能力层动态（推荐）

**做法**：skip(l) = static_mask(l) ∨ [l ∈ 检索能力层 ∧ dyn_signal(l) < τ_dyn]。即结构层永远跳（静态知识，证据最强）；检索能力层（E6 层 17-34）才允许动态判定，且用 p95 + 更小 τ（如 0.002-0.005）。

**依据**：结构知识和请求信号各用在其证据最强的范围——E5b 否掉的是「跨任务固定检索层的使用模式」，没否「局部层永远局部」；E75 分离度弱（~3× gap）说明信号只在「接近零 vs 显著非零」的粗判定上可信，细粒度分派不可信。

**优势**：风险敞口最小——动态误判只可能发生在检索能力层，而这些层的 τ_dyn 更严；static 下界保证 dynamic 永远不会比 M1 差；叙事上是「结构指纹 + 请求确认」两层防线，比纯信号语义好写。

**弊端**：
- 实现比 M2 多一个层集合参数（检索能力层集合从哪来：E6 avg_profile > 0.02 的层，需随主表配置重校准）；
- τ_dyn 与静态阈值两个旋钮，扫参成本翻倍（建议 τ_dyn 只扫 2-3 个点）；
- 若 E67 的「保守 τ 不触发」在检索能力层上同样成立，混合语义退化为 M1（但这本身就是有价值的研究结论）。

**改进点**：检索能力层集合不做成新超参，直接从校准 trace 的 avg_profile 派生（>τ_struct 即检索能力层），与 static 掩码同一次校准产出。

### M4 decode 期在线周期重估（dyngate 形态）

**做法**：不锁存，每 N 步（或检测到上下文切换/新 prefill）用最近 W 个 decode q 重算 far 统计，滑动更新跳层集合。

**依据**：E67 注释提到在线逐步 dyngate「已证 e2e 无损（−0.17 噪声级）」；直接回应 M2 的锁存假设弱点——decode 期出现的检索需求能被后续重估捕获。

**弊端**：
- 每步/每 N 步有信号开销（虽可摊销：W 个 q 已算过 attention，复用其 softmax 分布即可，增量成本近零——但 harness 的 eager_decoding 不物化全量 softmax，需要额外采集，工程侵入 decode 热路径）；
- 跳层集合随时间变化 → mask 形状变化 → CUDA graph 和生产 kernel 的最大敌人；
- 决策滞后：重估发现「这层又开始检索了」时，前面若干步已经在跳层状态下生成，损失已发生（不可恢复，decode 不回溯）；
- 论文 line 41 的表述是 prefill-once 形态，改在线形态需要同步改论文。

**改进点**：若做，只作为「锁存失效检测器」而非主机制——每 N 步检查一次被跳层的 far 需求是否复活，复活率 >1% 则证明锁存假设失败，为 M2 提供反证监控而非替代方案。

---

### M5 任务族分派静态掩码

**做法**：按任务族（多跳检索 / 长文摘要 / 代码）各校准一份静态掩码，运行时按请求分类选用（与 β 的「按任务形态二选一」双臂方案同构）。

**依据**：E75 的 family_dispatch 实验（β 分派）结论可迁移参考。

**弊端**：**E75 已判死**——β 的族分派增益 50.58 vs 50.54 为噪声级；且需要请求分类器（新组件、新误判源）；E5b 的 per-task 校准失败（长度/GQA 口径失配）同样适用于族级掩码。**不推荐，仅记录备查。**

---

### M6 双向 gate（skip_near）——已否决，记录理由

**做法**：E67 原始设计的另一半：prefill near band mass < τ_n 的层，decode 跳 near 池（只算 far+sink+swa）。E67 离线帕累托上这是最保守的臂（τ0.05 跳 14.3% 层、mass 损失 0.8%）。

**否决理由**：
1. 与论文核心 observation 直接冲突——让渡律（line 79「budget should concede toward near」）建立在「near 段 dense、高分者挤占配额」上，跳 near 需要把 observation 改写成层条件版本，叙事成本远超收益；
2. E87 实测 near 侧放松 e2e 证据混合：near_σ8 hotpotqa +0.85 但 musique **−1.63**，skip_near 比 σ 放松更激进；
3. mass≠e2e 铁律下，near band token 的 e2e 权重（局部连贯性、答案邻近性）很可能高于其 mass 占比；
4. swa floor 虽保送，但 mid-near band 是 swa 与 far 之间的缓冲，砍掉后 near 池语义空洞化。

## 4. 风险点清单（R1-R8，按严重性）

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R1 | **prefill 锁存假设在长 decode/多轮/agentic 下失效**（多跳检索需求生成期才出现，prefill 统计低估） | 静默精度损失，OOD 场景 | M3 严 τ + p95；DoD 加 2K+ 步漂移压力测试；多轮 clear() 重判 |
| R2 | **动态边际 ≈ 0**（E67 保守 τ 下 far 信号 0/168 触发） | 全部工程投入无收益 | 判决标准前置（§5）；主指标 = dynamic vs static 边际 |
| R3 | **mass 阈值 ≠ e2e 安全**（低 mass 关键 token 被跳） | musique 类任务静默掉点 | τ 选举走 e2e 不走 mass；τ 梯度复现 line 182 后再全量 |
| R4 | **信号/决策区域口径不一致**（E60 用 near_len=2048、E67 用 SWA1024/NEAR4096、runtime 用 swa=128+α·mid，三套都不一样） | τ 不可移植，数字全错 | 区域计算抽共享 helper `_region_bounds()`，compute_mask 与信号共用（单一数据源） |
| R5 | **τ 与「no tuning」卖点冲突**（line 79） | 审稿人并列质疑 | 论文表述为「safety-conservative switch」而非「parameter」；给 τ 梯度证明不敏感区间 |
| R6 | **生产形态成本**：batch 内 per-request 跳层集合 → kernel/graph 可变形状 | sglang 集成受阻 | 论文一句话边界声明；决策 prefill 锁定、graph capture 前定型；批量取并集或按请求分组 |
| R7 | **跨请求状态泄漏**（indexer per-layer 实例跨请求复用） | 上一请求的跳层决策污染下一请求 | clear() 重置 `_gate_decided/_gate_far_stat`（E85f `_pair_idx` 同款教训，line 710-712）；DoD 加连续两请求等价 fresh 实例单测 |
| R8 | **chunked prefill 信号缺失**（patch line 50 的 prefill 判定只对首 chunk 成立，后续 chunk 走 decode 分支） | 长文 chunked 场景 gate 失效或退化 | 代码 assert + 文档声明边界；信号缺失时保守不跳（fallback 到 static 或 none） |

## 5. 判决标准（事先约定，避免事后合理化）

E111 出数后按以下规则决策：

1. **dynamic@τ0.005 边际跳层率 <5%（相对 static 13/36）且 e2e 差分在 ±0.5 噪声级** → 结论「skip 集合由模型结构决定，静态掩码即终态」；论文 line 41/182 gate 段收窄为 static 表述；动态代码保留为消融臂。
2. **边际 ≥5% 且 e2e 无损** → dynamic gate 成立，兑现 line 41 claim；按 M3 混合语义定稿；补 R1 压力测试。
3. **边际存在但 e2e 有损（超噪声级）** → 降 τ 一档复测；仍有损则回规则 1，并在论文 limitation 写明「per-request 信号的 e2e 安全性不成立」。

## 6. 具体实现建议（给 E111 agent 的任务书要点）

### 6.1 代码改动（全部收敛在「决策来源」一处，下游兑现逻辑零改动）

1. **区域边界单一数据源**：从 `compute_mask`（line 470-479）抽出 `_region_bounds(t) -> (sink_tok, far_hi_tok, swa_lo_tok)`，`compute_mask` 与信号采集共用。这是 R4 的根治措施，先于一切其他改动。
2. **信号采集**：`observe_prefill_gate(q, k_full)` 挂 `qwen3_attn_patch.py` line 55 旁路（**扩签名传全量 K**——cache update 在 line 41-44 已完成，`key_states` 即全量缓存）。末段采样 M=16 个 q，逐 q-head 全量 softmax（E60 口径），mean + p95 双统计量都存。S 分块控制瞬时显存。成本预估 <0.01% prefill FLOPs，需实测 prefill 延迟增幅写入交付。
3. **决策锁存**：`_resolve_skip()` 按模式分派——none 恒 False / static 查 `_skip_ids` / dynamic 读锁存（`skip_far = _gate_decided and _gate_far_stat_p95 < τ`），信号缺失保守不跳。`clear()` 重置全部 gate 状态。
4. **CLI**：`--tli_layer_gate {none,static,dynamic}`（默认 none=现主表口径）、`--tli_gate_tau 0.005`、`--tli_gate_stat {mean,p95}`、`--tli_gate_log <path>`；`--tli_enable_layer_skip/--tli_layer_skip_path` 映射 static 保持向后兼容。
5. **下游复用**：far 块 −inf（line 482-484）、nb_far 收缩（line 512-517）、kmeans 跳过（line 210/251）全部不动。

### 6.2 DoD（按序执行，CPU 单测先行）

1. gate=none 与现状逐位一致（回归保护）；
2. dynamic@τ=0 ≡ none；static ≡ 现 DEFAULT_MASK 行为；
3. 信号口径校验：runtime 实采 far_stat vs E60 trace 重算，同样本误差 <1e-3；
4. 连续两请求：第二请求信号重采、决策等价 fresh 实例（R7）；
5. mavg/aavg × 三模式全组合 smoke（正交性）；
6. GPU：dynamic@τ0.005/0.015 跑 musique+qasper e2e，复现 line 182 梯度（+0.2/−0.4 区间）——**兑现论文已 claim 的数字**；
7. GPU：13 任务全量 @ 选定 τ + per-task 跳层率 JSON dump；
8. 开销实测：prefill 信号耗时占比 + decode 选择链省算 ms（对齐 29.5ms/step@8K 基线）；

## 8. 数学工具箱：线性代数与统计方法在本问题中的应用（by kimi-k3）

> 本节用线性代数与统计决策理论重新审视跳层 gate 与两级索引中的启发式做法，
> 按「对 gate 问题的直接价值」排序。目标：把启发式替换为有保证的规则、
> 给论文补理论严谨性、把定性担忧转化为可测量量。

### 8.1 τ 决策规则 → 条件风险界 / conformal prediction（最直接可用）

**现状问题**：τ 靠网格扫描 + e2e 验证，是裸启发式，且与论文 line 79「no tuning」卖点冲突。

**数学化**：设 $X$ = prefill far 信号，$Y$ = decode far mass（每层每请求）。gate 是单边决策，
风险天然不对称（false skip 灾难性，false keep 只是浪费算力）——正是 Neyman-Pearson 式
单边控制场景：控制误跳率 $P(Y > \varepsilon \mid \text{skip}) \le \delta$，约束下最大化跳层率。

由 E60 实测 corr 0.94-0.99，若 $(\log X, \log Y)$ 近似联合正态、相关 $\rho$：

$$\log Y \mid X=x \sim \mathcal{N}\Big(\mu_y + \rho\frac{\sigma_y}{\sigma_x}(\log x - \mu_x),\ \sigma_y^2(1-\rho^2)\Big)$$

取 $\tau$ 使 $P(Y > \varepsilon \mid X = \tau) = \delta$，τ 从「扫出来的数」变为「由 δ 推出的校准值」。

**免分布假设版本（split-conformal）**：用现有 calibration trace，非 conformity 分数取
$Y$ 的条件上分位数残差，有限样本下保证 $P(Y \le \varepsilon \mid \text{skip}) \ge 1-\delta$，
与分布假设无关，可在 held-out trace 上直接验证 coverage。

**收益**：τ 的叙事从「性能超参」变为「统计保证的置信水平 δ」（如 δ=0.01），
化解 R5（τ 与 no-tuning 卖点冲突）；审稿攻击线从「你调参了」变为可验证的
「guarantee 是否 empirical 成立」。

### 8.2 gate 形式最优性 + 平坦性 → Lagrangian / 包络定理（论文理论段）

**为什么「far mass < τ 就跳」的规则形式是对的**：跳层决策写成约束优化——
每层 far 跳过省算力 $c_l$、损失 decode far mass $m_l$：

$$\max_{S} \sum_{l \in S} c_l \quad \text{s.t.} \quad \sum_{l \in S} m_l \le \varepsilon$$

分数背包的 Lagrangian 松弛最优解 = 按 $c_l/m_l$ 排序取前缀；每层省算近似均匀
（0.82ms/step@8K，e67_gate_benefit）→ 规则退化为「按 decode far mass 升序跳」= 阈值规则。
**τ 即 Lagrange 乘子，现有设计形式是 Lagrangian 最优的。**

**真正的最优规则（$m_l$ 不可观测、只有含噪预测 $\hat m_l$）**：风险不对称 + 异方差下的
贝叶斯最优形式是 UCB：

$$\text{skip}(l) \iff \hat m_l + z_\delta \cdot \sigma_{\text{pred}}(l) < \varepsilon$$

**这把 §3 的 M2/M3 统一了**：σ_pred ≈ 0 的层（结构层）自然落入静态集合；
σ_pred 大的层（检索能力层）自动被保守化。混合语义不是工程补丁，是异方差下的最优规则。

**平坦性的理论表述**：E-law 的「oracle per-task +0.08 / per-layer +0.0008」本质是
**包络定理**——预算分配是凹目标（far 饱和律 = 边际捕获递减）下的约束优化，
最优点处分配扰动对最优值只有二阶效应。「不需要调参」是凹优化在平坦曲率点的
解析性质，非经验巧合，论文一句话即可立住。

### 8.3 R1（锁存假设失效）→ 自相关衰减 / 混合时间（CPU 可测，建议 E111 DoD #0）

多跳检索需求在 decode 中「涌现」⇒ per-layer far mass 是带跳变的随机过程；
prefill 锁存 = 用初值预测整条轨迹。预测有效期的刻画是过程的**混合时间**，
实操量为**自相关衰减**：

$$\rho_l(\Delta) = \operatorname{corr}\big(m_l(t),\ m_l(t+\Delta)\big)$$

**用现有 trace dump（E60/E67 的 ~255 decode q 已在 /tmp/trace 盘上）直接计算
$\rho_l(\Delta)$ 随 lag 的衰减曲线，纯 CPU、零 GPU**：

- $\rho_l$ 在 2K 步内保持 >0.9 → 锁存假设在测量范围内成立，R1 降级为外推风险；
- 数百步内显著衰减 → 锁存假设证伪，转向 M4（周期重估），且衰减率给出
  重估周期 N 的理论取值（如 $N = \min\{\Delta : \rho(\Delta) < 0.9\}$）。

**建议排进 E111 DoD 第 0 位：做动态实现之前先测这个数。**

### 8.4 「no miss」声明的量化漏洞 → Hoeffding/Bernstein 收紧（论文严谨性）

论文核心声明「块 minmax 上界保证子空间协议内无 miss」，但上界在 **4bit 量化后**的
min/max 上计算，量化误差 $\varepsilon_i$ 使界偏差可达 $\sum_i |q_i|\varepsilon_i$——
严格说 no-miss 只在未量化子空间成立。两种修法：

- **最坏情形（Hölder, ℓ1-ℓ∞）**：上界膨胀 $\|q\|_1 \varepsilon_{\max}$——严格但过松；
- **高概率情形（Bernstein/Hoeffding）**：量化误差近似独立均匀，$\sum_i q_i\varepsilon_i$
  集中在 $\mathcal{O}(\|q\|_2 \varepsilon / \sqrt{3})$ 尺度，膨胀 $z_\delta \|q\|_2 \varepsilon$
  即得 $1-\delta$ 概率 no-miss，膨胀量比 ℓ1 界小约 $\sqrt{d}$ 倍。$\|q\|_2$ 每步 O(d) 可算，近免费。

收益：声明从「近似成立」升级为「以 $1-\delta$ 概率成立且膨胀可忽略」，
堵住审稿人沿量化误差攻击的线路。对应 `tia_indexer.py` line 22-23 的
min/max per-token 量化处。

### 8.5 tail32 的解析推导 → RoPE 低通截止公式（理论亮点，可检验预测）

RoPE 是 2×2 旋转块的块对角正交变换，第 $j$ 对频率 $\omega_j$，$q \cdot k$ 中该对贡献
随相对位置以周期 $2\pi/\omega_j$ 振荡。块内 min/max 索引要紧致，要求块长 $B$ 内
振荡不充分：

$$\omega_j \cdot B \ll \pi \;\Rightarrow\; r(B) = \#\{j : \omega_j < \pi / B\}$$

$B=64$ 时截止恰落在最低频 ~16 对——**tail32 不是搜出来的，是 block size 的函数**。
两个可检验预测：

- (a) 换 block size 时最优 d' 应按 $r(B)$ 缩放——一次小消融即可验证，验过即是论文理论结果；
- (b) 高频对崩溃（E 数据 recall 0.004）与 random 32 维崩溃（0.32）的解析解释：
  高频对在块长尺度多次振荡，静态 min/max 包不住有效信息。

**训练投影 e2e 崩的理论表述**：保 q·k 排序的最优 r 维双线性投影是 **q-k 互协方差
$C = \mathbb{E}[qk^\top]$ 的截断 SVD**（不是 key 的 PCA——目标不是重建 k，是保跨域内积）。
prefill 上估的 $C$ 与 decode 的 $C$ 漂移 ⇒ 任何数据驱动基继承漂移；
频率先验由 RoPE 结构（架构常量）决定，与数据分布无关。
**E66/E85f 的 negative result 有干净表述：trainable basis 估的是漂移对象，
frequency prior 估的是不变对象。**

### 8.6 上界的支持函数视角 → 下一代索引收紧方向（备查，不进 E111）

块 minmax 界 = 轴对齐包围盒（AABB）的支持函数
$h_{\text{box}}(q) = \sup_{x \in \text{box}} q^\top x = \sum_i \max(q_i \min_i, q_i \max_i)$
（Quest 与 TIA/PSI 的界在数学上同一形式，见 `quest_indexer.py` line 51-53 与
`tia_indexer.py` line 87-88——注意：论文 line 35/133「Quest = lower bound」的表述
与此矛盾，Quest 原版与你们的实现都是**上界**，Quest 的失败模式是界松 →
无关 page 过估计 → 挤兑真 page，非「低估漏检」，建议修正表述）。

松的根源：AABB ⊋ 块内真实 key 点云（64 个语义相关 token，协方差强各向异性）。
收紧路径：**PCA 对齐旋转盒**——块内 key 协方差 top-r 方向 $U$，界为旋转坐标下的
盒支持函数 $\sum_j \max((U^\top q)_j a_j, (U^\top q)_j b_j)$，界体积按各向异性比收缩；
代价每块一次 $U^\top q$ matvec，与 sup_wsvd/PCA 探索线衔接。旋转盒若仍精确包住
点云则 no-miss 性质保持。

另注：GQA 组内 mean 聚合（E103 验证为 denoiser，−1.65 若 per-q-head 独立）的数学注记：
mean of support functions = support function of Minkowski 平均盒，对组均分的上界性质
不严格保持，但作为块分估计的 4 样本方差缩减（σ²/G）成立——E103 结果与
「块分级噪声主导」一致。
