# PSI 子空间部分审稿意见

日期：2026-10-06。范围：当前稿 §II-A、§III-A、相关表示消融及泛化主张。下述补实验均为建议，尚未执行；不涉及修改 SGLang。

## 总体判断

**固定低频完整 RoPE 对可以保留为经验先验，但“物理尾维”“频率语义”“跨模型有效性”必须分开。** 把数组切片改成布局无关接口是必要的正确性修订，不自动构成新贡献，也不能证明低频始终保留最重要的 attention 信息。

已核实的当前事实：

- Qwen3 的128维头全部参与RoPE；`[48:64] + [112:128]` 是16个完整低频对，共32维，后一半不是NoPE。
- 主质量配置是 **L1 full128 + L2量化低频32维**；低维L1是另一实验臂，不能混用它的成本解释主配置质量。
- 可选L2投影分支与固定选维不同。已读校准脚本对未中心化K做截断SVD，不应无条件称为PCA或“低频子空间”。[1]

当前稿已澄清前两项及上界限制；以下意见要求补足方法定义和证据，不重复指控这些旧表述错误。

## P0 必须先关闭的正确性问题

### S1 按频率对定义子空间，不能按固定地址定义

**问题与影响：** `head_dim`不能单独确定旋转范围、配对布局或缩放后的频率。换模型继续取两半尾部，可能选错旋转对或混入NoPE维。

**修改建议：** 显式定义每层旋转维度`d_R`、NoPE集合、频率对ID到物理坐标的映射，以及实际相位/缩放规则。split-half配对是`(j,j+d_R/2)`，adjacent配对是`(2j,2j+1)`；存在重排时先映射。读取实际频率和cache使用的缩放版本，而非只读取`rope_theta`。[2]

**最小验证与验收：** 对同一Q/K同步置换坐标、RoPE映射及选维集合，测试split-half、adjacent、随机置换和partial-RoPE。完整分数、同语义子空间分数及选择集合应在预设数值/tie规则下等价；固定物理tail作为负对照。失败先修映射，暂停泛化结论。此测试只证明等价布局正确，不能替代跨模型质量实验；坐标min/max上界也不具有任意正交旋转不变性。

### S2 区分完整分数、代理分数和级联损失

**问题与影响：** 子空间内的块上界不一定界住全维分数；按上界固定取top-K块也不保证不漏真top-token。最终在所选KV上用全维attention，不会恢复已漏掉的位置。

**修改建议：** 分别写清L1和L2的表示、选维/投影、量化与head聚合。保留当前稿的“近似筛选、无no-miss保证”限定；若声称量化界仍有效，补外向舍入或误差项。[3]

**最小验证与验收：** 同一trace先绕过L1测试精确子空间排序，再加入固定L1，最后加入量化；分别记录候选召回、attention-mass和输出误差。full-score oracle须匹配强制保留及区域约束；无约束oracle另标。若损失主要发生在L1，不得归因于选频；若仅回放recall改善，不能写成任务质量提升。

## P1 决定子空间贡献是否成立的证据

### S3 低频稳定不等于重要，需正面对照FASA

**问题与影响：** 相位变化较慢只是几何动机；对完整分数的贡献还取决于Q/K幅值、内容和层。现有八样本回放不足以证明跨模型规律。

**相关工作边界：** FASA正式ICLR 2026论文已采用完整频率对、每头校准、低维筛选后全维计算；§6还报告Partial-RoPE实验。其附录B.1的LongBench设置仅用一个Qasper样本校准，不能预先把校准成本视为巨大。[4] SparQ也已有query-dependent通道筛选。[5]

**修改与实验：** 固定L1、区域配额、真实唯一KV预算、head共享和精度，仅更换L2：低频/中频/高频完整对、随机完整对、错配坐标、FASA规则校准对；先统一32个标量维。查询自适应通道、SVD32作为下一层替代方案，不一开始铺满网格。相同骨架中的“FASA规则选对”是组件消融，不能冒称完整FASA复现。

**判定：** 若校准对在holdout更可靠且成本相当，应将固定低频定位为特定条件下的免校准点。若新模型失败，则收窄适用范围；不能把“完整对是正确单位”写成“最低频对必然最好”。

### S4 真正混合NoPE与RoPE时，需明确内容分量策略

**问题与影响：** 对已施加RoPE的分量，原模型分数为`scale × (q_Cᵀk_C + q_Rᵀk_R)`。只保留低频RoPE可能丢失内容分量；NoPE没有可直接沿用的旋转频率排序。两部分也不能默认各自归一化后等权相加。[6]

**修改与实验：** 用`d_index = r_C + 2r_R`统一标量维预算。先比较32维RoPE-only、32维NoPE-only、16维内容+8个完整RoPE对；内容维的选择规则在独立calibration/dev上冻结。保留原始相对尺度，若学习额外权重须另报校准。可用Phi-4-mini的96 RoPE+32 NoPE及LongRoPE作为小型真实边界测试。[7]

**判定：** 混合方案成功只支持该新方案，不能回写为原始RoPE-only已普适。交替NoPE/RoPE层是另一边界，partial-RoPE成功不能替代它。若扩展到MLA，应直接使用latent cache与吸收后的query，不重建整段高维KV；latent尾部不是低频，选择少量原始NoPE坐标也不保证吸收后的dot变低维。[6]

### S5 校准目标、泄漏与实际代价必须单独核查

**问题与影响：** K的重构误差小，不保证`qᵀk`排序或任务误差小；post-RoPE SVD也不是频率对选择。静态校准对“回放好、生成差”的现象不能唯一归因于query drift。

**修改与实验：** 按原始文档划分calibration、dev和test；同文档的问题、长度变体、近重复不得跨集合。记录校准样本、层/头、prefill/decode位置、候选选择次数与投影基。分别比较固定对和校准表示的跨任务/长度迁移。

**判定与成本：** 报实际索引字节、构建/更新、query投影、gather和选择延迟，校准成本单列。等维数不等于等计算或带宽。若通用方案依赖校准，应称“免训练但需校准”，不能继续称“免校准”。若局部输出更好而完整生成不改善，停止用recall替代任务指标。

## 最小补实验与统计要求

| 阶段 | 最小内容 | 必须固定或记录 |
|---|---|---|
| P0 | S1映射等价测试；S2表示/级联分解 | pair map、cache版本、数值容差、有效唯一位置 |
| P1 回放 | Qwen3同一批trace；32维主对照，仅入围两种表示补16/64维 | L1、配额、K=1024、强制集、head规则、量化分开 |
| P1 确认 | Qwen3与Phi-4-mini；8K/24K；两类任务；dense、冻结低频方案、忠实FASA，共24单元 | 真实token长度、同例配对、统一实现、未参与选择的test |
| P1 混合边界 | Phi的8K两任务行追加NoPE-only和冻结混合表示，共4单元 | 总32维；不得事后挑赢家替换原假设 |
| P1 DeepSeek | V2-Lite先做4K/16K MLA回放，再做同checkpoint三臂×两长度×两任务，共12单元 | 原生latent缓存、NoPE/RoPE配比、held-out校准与真实成本 |

两类确认任务优先采用多证据检索聚合、真实长文QA；具体数据和scorer在执行前冻结。FASA的Partial-RoPE细节若仍未核实，应标为明确的自实现适配，不能称忠实复现。以上单元数不是已批准运行量，样本数仍由独立pilot和资源决定。

- 质量的独立单位是文档/底层实例，层、头、token不是独立`n`；按文档簇配对重采样并保留官方metric与任务macro规则。
- Q/K/V回放只能给局部attention指标；logit/NLL需额外teacher-forced sparse forward，任务质量需独立rollout。
- 确认前预设相对FullKV的可接受损失、CI精度与比较族。例如macro非劣界1.0点、95%区间半宽0.5点仅是待论证的提案，不能套已有结果事后宣称通过。
- 用独立pilot规划固定样本量；不“跑三次就够”，不加样本直到显著。随机子集的不同seed也不能充作文档重复。
- 同一实现、相同工作量下计时，按独立session交错配对，包含投影和索引维护。区间跨验收界限时记为“不确定”，非显著不等于等效。

## P1 新增DeepSeek跨模型验证

**审稿意见：** 当前证据来自Qwen系列，跨尺寸仍不能代替跨模型家族验证。建议保留Qwen基线，将一个真实DeepSeek MLA模型纳入这轮子空间补实验；Phi的partial-RoPE实验不能替代MLA缓存结构的验证。

**首轮模型：** 优先DeepSeek-V2-Lite，固定checkpoint、tokenizer与实现版本。官方为16B总参数、2.4B激活参数、32K上下文，内容NoPE分量128维、RoPE分量64维、latent KV维度512。[10] 这是dense MLA模型，不是“小型DSA”；若选Chat版，应单独锁定其模型和配置。

**有限矩阵：**

1. 先在独立held-out文档上采集4K/16K trace，核对吸收形式与显式小样本完整分数一致。复用同一trace比较内容-only、低频RoPE-only、内容+低频三种表示；主维度预算32，混合臂为16内容索引维+8个完整RoPE对。另加全部64维RoPE与RoBSA代理作为结构近邻对照，明确其维度不同。[8]
2. 内容表示须明确是原始NoPE坐标还是共享latent投影，不能把512维latent dot当成32维计算。projection、额外cache及head复制全部计成本；两分量保持原模型相对尺度。配比、内容选维、校准基只在calibration/dev选择，冻结后进入test。
3. 再用同一DeepSeek checkpoint做full attention、冻结PSI适配、FASA适配三臂，4K/16K×两类任务，共12个确认单元；先导决定每单元样本数。FASA的MLA适配若无法核实，须标注为自实现并说明改变，不能称官方原样复现。NoPE/RoPE混合臂只有回放显示必要时才追加完整生成，不扩成全笛卡尔积。

**公平条件和指标：** 稀疏臂先统一真实唯一token预算K=1024，包含sink/window，写清每头或跨头共享及union后的实际读取量。固定L1、配额、精度和强制集，只改变子空间；同时报告维度、token-head entries、实测字节和成本。回放看完整分数top-K位置召回、attention-mass和输出误差；额外teacher-forced forward比较下一token分布KL/NLL，独立rollout比较任务分数。不要对未选token直接置零的注意力分布计算会发散的dense-to-sparse KL。计时包含索引构建/更新、投影、选择与gather，存储包括辅助索引及latent cache。

**判定：** 相对同模型full attention按预设质量界和区间验收；固定低频失败而混合/校准方案恢复时，支持的是新适配方案，不能称原版低频先验普适。若只有局部召回改善，仍不能宣称任务或速度提升。Qwen和DeepSeek分别报告方法内差值，不用跨模型绝对分数排名证明子空间优劣。

**资源与范围：** BF16按2 bytes/参数，16B仅权重粗估约32GB，不含KV、激活、工作区与碎片；2.4B激活参数不代表只需加载2.4B权重。实际设备、精度、峰值显存与预算尚未确认，不能承诺某张GPU能跑。本节为实验计划；代码修改、模型运行及新增硬件使用须另行确认，SGLang仍保持只读。

### 可以与DSA比较 但需要原生DSA模型

**可以比较，且这是有价值的后续实验。** 普通DeepSeek-V3的MLA不等于DSA；V2-Lite只能先验证混合表示与MLA适配。原生DSA从V3.2-Exp引入，V3.2延续该路线，包含训练过的Lightning Indexer和模型对稀疏模式的适应。[9] 应选择并锁定一个实际含DSA的官方checkpoint，先核实PSI适配器及真实稀疏kernel能否接入，再批准整模运行。

| 实验臂 | 选择器 | 必须保持一致 |
|---|---|---|
| A 原生DSA | 原模型learned indexer及原生top-K | checkpoint、主模型权重、输入token、因果候选范围、最终MLA计算与运行环境 |
| B PSI替换 | PSI适配器输出token indices，送入同一最终MLA路径 | 同上；统一真实唯一token预算、跨head共享域、精度、位置编码和attention scale |
| 可选诊断 | 完整主注意力分数top-K或forced-dense | 标为干预参照，不能默认是任务质量上界 |

首先匹配原生配置的top-K语义，例如官方V3.2-Exp的2048个位置、跨MLA heads共享；不能拿PSI的1024与DSA的2048当同预算。[11] 原生DSA不因对照而任意改造。若PSI额外保留sink/window，必须计入K，并加相同保留策略的控制，防止把保留规则收益归给子空间。

两种选择器的分数不等价：DSA使用自己的learned表示，PSI拟用主MLA内容/旋转分量构造辅助分数。适配器须明确读取latent/rotary cache、内容投影、索引更新、位置到物理cache槽的映射及额外存储；不能把导入一个DSA top-K kernel当作原生DSA系统。DSA indexer与主MLA的RoPE布局也须分别核验，不能共用未经验证的pair map。[12]

**测量分两步：** 先在同一hidden-state trace比较候选集合与selector成本；再用相同tokenized prompts做自由生成，观察误差累积及任务质量。优先隔离decode选择器，prefill保持相同原生路径；若同时替换prefill，另列实验。报告选择器总耗时、请求/生成时延、质量、实际KV读取和辅助存储，包含投影、维护、gather、同步。对真实shape预热，跨独立session交错配对；固定输出步数计时与自然EOS请求分开。

**结论边界：** 即使checkpoint相同，主模型此前已经适应DSA；实验回答的是“冻结已训练DSA模型后，PSI能否直接替换”，不能直接证明两种方法在相同训练条件下谁更优。训练成本与新增校准成本分别报告；若微调，则新增明确实验臂、匹配数据/算力预算，不能只训练一方后宣称公平。Qwen+PSI与DeepSeek+DSA的跨模型分数不能用于selector因果排名。**先完成V2-Lite必要条件；671B整模DSA不是本轮子空间修订的前置条件。**
